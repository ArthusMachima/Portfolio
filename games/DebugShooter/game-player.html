DE:BUG

DE:BUG is a game about shooting literal bugs. The game was my first attempt on implementing proceedural map generation and inventory system. I made this game as a requirement for a major subject.


How to play:

  • WASD - Movement
  • Left Mouse - Shoot
  • R - Reload
  • E - Open Inventory
  • Esc - Pause / Back
